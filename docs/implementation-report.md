# 実装と確認範囲

バンド評価値計算、育成変換、機械的な選出、所持管理とイベント周回計画を実装しています。実データを含まない静的Webアプリで、マスタ・所持・ランク定義・変換プロファイルは利用者がJSONで登録します。

catalogの構造・意味・所持参照を検証し、空起動、不足表示、破損保護、保存失敗時のExportを扱います。キャラクターランクは手入力を優先し、未入力分だけ登録済みの外部定義から推定します。定義が不足する場合は未算出として表示します。

公開テストは架空データで計算・入力・保存・JSON往復・不正入力の非破壊拒否を検証します。ChromiumとiPhone相当のWebKitでUIを検証します。WebKitエミュレーションは実機Safariの検証とは区別します。実際の検証状態はActionsを参照してください。

同梱データの範囲は[公開データの範囲](separation.md)、期待値の根拠は[テスト](testing.md)、未検証のゲーム仕様と算出の限界は[計算仕様](calculation.md)に記載しています。自作コードは当面ライセンスなし（All rights reserved）。Vite等の必要な権利表示を配信物にも同梱します。
