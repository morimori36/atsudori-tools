# 計算・選出と検証範囲

これはバンド評価値の推定式を実装した非公式ツールです。総合力や評価値を最大化する探索は行いません。総合ランクボーナスを独立した入力として扱います。元の実測値・画像・転記・原本はこのリポジトリに掲載しません。

## 表示値からの評価値

Sをメンバー詳細の表示P/T/V、Aを式の覚醒、L/GをLive/撃奏Lv、rをキャラランク、Tを総合ランクの各パラメータへのボーナス、bをバンドアイテムの小数補正とします。

```text
h = (2A + L + G) / 100
C = 5(r - 1) + T
X_i = floor((S_i * (1+h) + C) * (1+b))
B = X_P + X_T + X_V
K = 1 + s_P + s_T + s_V + 0.02U
E = floor(B * K)
```

Tは総合ランクのボーナス欄の値です。個人ランク分を含む合計ボーナスとは区別します。総合ランクの値自体を直接加算しません。手入力を優先し、なければImportしたランク定義のtotalRankBonusesを全キャラの現在ランク合計で参照します。表・対応行・ランク合計が欠ける場合は評価値を保留し、旧固定値へ戻しません。育成最大の表示でも合計は現在の所持・ランクから求めます。

sは表示Snap％の小数倍率、Uは上限解放段階です。SnapなしはK=1として明示的に扱い、ゲーム内Lv0を定義しません。

内部ではBigIntの整数演算を使います。Snap表示3.21%は321（分母10000）、item1.3%は13（分母1000）。各P/T/Vの切捨てと最終切捨てだけを行い、途中で小数を丸めません。安全な整数を超える結果は拒否します。

採用式は非公開に保持する条件明示の転記観測と、仮定を分けた診断に基づきます。転記元の一次画像は再確認できていません。仮定付きの一致を確定実測として数えず、公開側では架空データで演算を検証します。未観測の組み合わせ・高い撃奏Lvなどをゲーム実測済みとは扱いません。覚醒係数2には連動リーダーの寄与が含まれ、独立な寄与を分離したものではありません。

## 育成から表示値へ

メンバーの各チャンネルは、基準Mと対応する3率を使い、次の整数3項を加算します。

```text
Lv項 = floor(f32(f32(M * rateLv) / 10000))
特訓項 = floor(f32(f32(f32(rateTraining) / 10000) * f32(M)))
覚醒項 = floor(f32(f32(M * rateAwakening) / 10000))
表示値 = Lv項 + 特訓項 + 覚醒項
```

f32はIEEE 754 binary32への丸めです。Snap表示％もLv項と同じ順序で基準BPを変換します。一括floorや単純なdouble演算へ変えません。対応していない数値範囲、Lv上限超過、欠けた行、A/UとスキルLvが連動しない形は拒否します。

この育成変換は整数演算とbinary32の丸め順を保つ自作実装です。item補正は対象となる所持アイテムの率を合算します。元の実測資料には個別アイテムLvがなく、全育成範囲や追加表示補正のゲーム検証を完了したという意味ではありません。

## 機械的な選出

選出単位はバンド→色→キャラクターです。各枠の所持メンバーは高レアリティを優先し、Snapは同色・対応キャラを候補とします。共有Snapを候補メンバーの高レアリティ順に割り当てます。使用済み管理はバンド・色内に限り、Snapを別バンドで再利用できます。

これらは従来のユーザー申告を受け入れた仕様で、ゲーム内部を直接観測した保証ではありません。暫定点は結果の※から読めます。

- 同順位カード/SnapはID昇順、受取メンバーはキャラID→カードID昇順。Import順には依存しません。ゲーム内tie-breakは未確認です。
- EX=SSR、BD=SRの比較順位を暫定適用します。元のrarityを育成や保存で変えません。その他の未知コードの大小は補完せず、競合は保留します。
- 複数代替Snapの逐次割当は暫定で、関係する枠へ注記します。評価値による最適化はしません。
- 未設定アイテムを持つ枠は保留します。キャラクターランクは手入力値があれば使用し、なければ[Importした定義でEXPから推定](character-rank.md)します。対応する定義がない場合は推定せず保留します。色またはバンドの一部が保留なら合計も保留し、計算できた小計を区別します。
- 登録がない枠を推測で補完しません。表示合計は登録分です。

「育成最大」は所持メンバーの特訓・Live・撃奏をcatalogの合法な最大段階へ、Lvを対応する上限へ変更した表示用コピーです。覚醒・Snap・ランク・アイテムは現在のまま、所持保存・Exportは変えません。

ランク推定の追加でも上記評価値式は変更しません。総合キャラクターランクは各キャラクターの使用ランク合計として表示し、対応する外部ボーナス表を参照し、個人ランク分とは別に加算します。
