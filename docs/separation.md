# 公開データの範囲

このリポジトリをWebアプリ実装の正本とします。計算・検証・ブラウザ内の保存と表示を扱い、利用者のデータはJSONとして別に管理します。

| 区分 | 取り扱い |
| --- | --- |
| 計算・育成・選出 | 自作の処理。式・演算順序・暫定条件は[計算仕様](calculation.md)を参照 |
| catalog | カード・育成等の共通定義を利用者が登録。リポジトリ・配信物・初期データには同梱しない |
| collection | 所持・育成・手入力ランク・進捗。ブラウザ内で保存し、独立したJSONでImport/Export |
| ランク定義 | ミッション条件・報酬・累積EXP・表示ラベルは利用者の外部JSON。公開側は汎用エンジン・Schema・検証・管理UIだけ |
| 変換プロファイル | 提供元で適合を確認した限定的な宣言JSONをImport。特定の出力先・実プロファイルは同梱しない |
| 周回プラン | マスタと独立した入力・計算・保存・JSON管理 |
| テスト | 完全な架空データ。実データ・原本・実測fixtureは公開CIへ渡さない |
| 配信物 | コード・スタイル・Schema・必要な権利表示だけ |

catalog・collection・周回プラン・変換プロファイル・ランク定義は個別に保存します。各format/versionと保存キーを維持し、不正・未知・不一致は補完せず理由を示します。参照を壊すcatalog更新は所持を削除せず拒否します。保存内容を送信・ログ出力しません。

外部サービスからの自動取得、ログイン、画像、編成最適化、任意コードの実行は含みません。実装の検証にはこのリポジトリの固定コミットを使い、非公開の検証資料が必要な場合も[外部の回帰入力](private-regression.md)として扱います。

自作コードは当面ライセンスなし（All rights reserved）です。Vite等の第三者ライブラリに必要な権利表示は維持します。公開範囲・本番配信・ライセンス方針の変更は所有者の承認を必要とします。
