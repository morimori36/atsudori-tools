# 変換プロファイルによるJSON出力

「JSON Import / Export」の「外部形式JSON」では、外部から登録した定義に従って、所持・育成情報をJSONへ変換します。特定の出力先を内蔵していません。出力先の形式調査・定義の生成・取り込み手順・互換性の確認は、プロファイルの提供元が担当します。

## 操作

1. 対応するcatalogをJSON Import / ExportへImportします。
2. 信頼できる提供元の変換プロファイルJSONを選び、自動検証後に即保存・更新します。識別子・版・ハッシュは「詳細情報」で確認できます。
3. 実際の所持・育成、ランク・進捗・アイテムを更新します。未入力アイテムは未知なので出力を止めます。未解放は明示的に登録してください。
4. 必要な場合だけ「仮育成設定を適用する」をオンにします（初期OFF・変更後はブラウザ保存）。評価値画面と共通の特訓・覚醒・ライブ・撃奏の目標を編集できます。現在値は下げず、目標以下の合法な最高値まで引き上げます。特訓が上がる場合だけメンバーLvを上限へ合わせます。初期設定は特訓5・覚醒は引き上げない・ライブ5・撃奏5です。
5. 「JSON出力」を1回押すと、検証・生成が成功した場合だけ即ダウンロードします。完全性チェックやプレビュー・追加確認は不要です。未入力データの補完は行いません。
6. 出力先への取り込みは、提供元の手順に従ってアプリの外で行います。このアプリで管理しない情報の扱いも提供元で確認してください。

登録中の所持JSONは変更しません。バックアップには従来の所持JSON Exportを使ってください。ランクは手入力を優先し、未指定なら通常の評価値と同じ推定処理を使います。推定は補正前の実所持から行います。未入力進捗、過去の所持・達成、報酬受取状況は再現できず、実際のランクと異なる可能性があります。

## プロファイル契約 v2

構造は[JSON Schema](../public/schemas/conversion-profile-v2.schema.json)、追加検証は`src/domain/conversion/profile.ts`で定義します。

| 項目 | 意味 |
| --- | --- |
| format / schemaVersion | `atsudori-tools/conversion-profile` / `2` |
| engine | `bounded-template/1` |
| id / version | プロファイルの識別子と版 |
| input | `atsudori-tools/collection` v1 |
| target | 出力形式の識別子、版、提供元が検証した定義のSHA-256。文字列をサービス名やURLとして解釈しない |
| catalog | 対応catalogのID、revision、canonical JSONのSHA-256 |
| provenance.sources | 提供元が管理する根拠の識別子・revision・SHA-256。1〜20件、識別子は一意 |
| program / output | 宣言的な変換手順と出力の構造・値域 |
| checksum | この項目自身を除いたcanonical JSONのSHA-256 |

マスタ更新とプロファイル更新は独立です。ただしcatalogのID・revision・内容ハッシュが一致しなければExportできません。同じrevisionの編集も不一致になります。未知の入力版・エンジン版・操作・項目、不正値、チェックサム不一致は拒否します。v1をv2として読み替えず、提供元での再生成を必要とします。

出力形式の識別子は外部定義です。このアプリは出力先の現行仕様を取得せず、出力先の変更も自動検出しません。提供元で確認したプロファイルだけを使用してください。ハッシュは改変検出用で、発行者の電子署名ではありません。

対応操作は`literal / get / object / array / concat / text / map / lookup / ifNull`だけです。読み取りは準備済みのメンバー・Snap・ランク・アイテム行、Export識別子・時刻・総ランクに限定します。ループの入れ子、危険キー、深さ・ノード数・実行量・出力容量の超過を拒否します。任意コード・外部参照の実行はありません。出力定義もobject・record・array・choice・string・integer・boolean・nullだけです。

保存キーは`atsudori-tools.conversion-profile.v2`です。catalog・collection・周回プランの既存キーとは独立しています。v1の保存内容にはアクセスせず保持します。破損したv2の元文字列も明示的な更新まで保護し、ダウンロードできます。容量不足などのImport保存失敗はエラーを表示し、既存のプロファイルと保存内容を維持します。

自動推定ランクを出力する場合は、対応catalog内のrankDefinitionも必要です。不足時は出力を停止します。全員の手入力ランクがマスタに対応すれば定義なしでも出力できます。推定は補正前の実所持から行います。

## ランク定義のcatalog統合との互換性

新しく生成するプロファイルはvalidateCatalogで正規化したrankDefinitionを含むcatalog全体の内容ハッシュに対応させてください。旧プロファイルは、catalogIdとrevisionが一致し、rankDefinitionを除く従来のcatalog表のハッシュも一致する場合に限り利用できます。カードや育成表の変更を無視する処理ではありません。新プロファイルがcatalog全体に結び付いている場合、ランク定義だけの変更でも不一致になります。

共通設定は `atsudori-tools.hypothetical-training.v1` に保存し、catalog・collectionとは分離します。両画面の編集を共有し、再読み込み後も復元します。破損設定は元の保存を保護して初期値を一時使用し、明示的な置き換えで復旧します。保存失敗は未保存と表示します。出力は保存した適用ON/OFFと共通設定を使用します。条件を変えた場合は再出力してください。通常の所持バックアップExportは常に実値です。

TGWランクは`meta.tgwRank`から参照できます。設定済みなら正の安全な整数、未設定なら`null`です。既存プロファイルは引き続き利用できます。対応値はプロファイルで確認し、未対応値は補完しません。
