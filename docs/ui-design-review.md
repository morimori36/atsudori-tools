# UIデザインの見直し

対象は現行Web `atsudori-tools`、初回の確認基準は `dc7db6f`（PR提出時に `1fb5aad` のmainを取り込み）、作業ブランチは `style/ui-design-review`。公開リポジトリのUI・既存の独立した架空fixtureだけを使う。計算・保存・JSON契約は変更しない。既存の[UI設計ルール](ui-guidelines.md)を前提に、共通シェルと初回の導線を見直す。

## 判断と今回の対応

| 観点 | 見つかった問題 | 対応 |
| --- | --- | --- |
| 初回の優先順位 | 評価値画面で、マスタ登録よりも表示モードと育成設定が先に現れる | 未登録・不整合時は、登録・復旧案内をDOM順で先に表示する。表示値計算の入口も残す |
| 見出しの意味 | 素材在庫やデータ管理にも `BAND RATING` が表示される | 英語の補助見出しを削除し、日本語タイトルと目的を使う |
| ナビの読みやすさ | PCは12px中心で、薄い紫の背景が作業領域と続いている | 項目14px・分類12pxとし、白いナビと中立色の作業領域を分ける。選択状態の文字・背景・線は保持する |
| 文字の階層 | 日本語タイトルの字間が狭く、スマホでは画面説明も12pxになる | 日本語UI向けのローカルフォントを優先し、見出し26〜32px、説明14pxにする |
| 面の階層 | 同じ丸い面と淡い影が反復する | 共通panelは10pxの角丸と境界線、ナビ項目は6px。共通panelの影を除く |
| 操作領域 | スマホのテーマ選択が36px | 44pxに広げ、文字は16px。固定ヘッダーとナビの基準高さも同期する |

## デザイン方針

繰り返し所持を編集して結果を比較する道具として、左揃えの見出し・操作・結果を追いやすくする。記憶に残る強調は既存の紫の操作色に集約する。ゲーム由来の画像や実データを装飾として追加しない。

| 基本色 | 役割 |
| --- | --- |
| `#f5f6f8` | ライトの作業背景 |
| `#ffffff` | ナビ・入力や結果の面 |
| `#222535` | 本文 |
| `#626778` | 補足 |
| `#6550bd` | 主要操作・登録案内の強調 |
| `#dedfe7` | 境界 |

ダークでは中立色の背景 `#202127`、本文 `#e2e3eb`、補足 `#b8bac9` と既存の紫のアクセントを使う。個別のレアリティ・カード色・保留・危険操作の意味は保つ。

フォントはヒラギノ角ゴ、Yu Gothic UI、Noto Sans JP、Meiryo、sans-serifの順で、配信フォントは増やさない。見出しより分類・補足を小さくし、画面説明と登録案内は60ch以内に制限する。

```text
PC:      共通ヘッダー（現在画面・テーマ・保存状態）
         分類ナビ | 日本語タイトル・目的
                  | 主要結果、または未登録時の次の操作
                  | 条件・詳細
スマホ:  共通ヘッダー（メニューから同じ分類ナビを開く）
         日本語タイトル・目的
         主要結果、または未登録時の次の操作
         条件・詳細
```

設計案の再確認では、各画面への英語ラベルや装飾の追加を避け、既存の日本語・紫の操作色・目的別ナビを軸にした。画面ごとの入力先行／結果先行と、明示保存／自動保存の違いは維持する。

## 表示確認

画像はGit・配信物に含めず、ローカルの `.cache/ui-review/` に置く。比較前後の初期画面と、既存の人工算術fixtureによるスター予算を使う。変更後は評価値・スター予算・イベント周回・表示値計算・JSON管理を320/375/390/1280px、ライト／ダークで確認する。14画面の移動・メニュー・フォーカス・保存は既存E2Eの対象。

実機Safari、スクリーンリーダーでの読み上げ、初見利用者の操作時間は今回の確認範囲に含まない。各画面固有の入力・表・カードの全面改修は別途、目的とデータ量に合わせて判断する。

初回の検証結果（main取り込み前）:

- `npm run check`: 型検査と単体550件が成功。
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`: buildとE2E224件が成功。環境に導入済みのChromiumを使用。
- 代表5画面・4幅・2テーマでページ全体の横はみ出しなし。1280/390pxの画像も目視確認。
- `npm run audit:public` と差分の内容レビュー: 成功。追加は表示・導線・設計文書のみで、新たなデータ・画像・依存ライブラリの持込みなし。
